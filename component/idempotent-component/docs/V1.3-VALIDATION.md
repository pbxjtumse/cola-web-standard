## 当前环境限制

当前生成环境没有 Maven 可执行文件，也没有本地 Maven dependency cache，因此没有宣称：

```text
mvn clean test
```

已经通过。

拿到项目后建议首先执行：

```bash
mvn clean test
```

然后重点：

```bash
mvn -pl component/idempotent-component/idempotent-core -am test

mvn -pl component/idempotent-component/idempotent-provider/idempotent-provider-jdbc -am test

mvn -pl component/idempotent-component/idempotent-integration-transaction -am test

mvn -pl component/idempotent-component/idempotent-demo -am test
```

## 建议的真实环境验收

1. Redis WINDOWED：
   - 首次 ACQUIRED；
   - 重复 SUCCESS replay；
   - PROCESSING_ACTIVE；
   - window expiry 后 version+1；
   - retention 尚未物理删除时仍能重新 generation。

2. JDBC DURABLE：
   - UNIQUE 并发首次抢占；
   - owner/version stale write rejection；
   - recovery expectedOwner/version stale candidate。

3. Transaction：
   - Business + SUCCESS 同提交；
   - callback 异常 -> Business rollback + Tx-C FAILED；
   - markSuccess stale owner -> Business rollback；
   - COMMIT_UNKNOWN 不写 FAILED。

4. ResultPolicy：
   - NONE；
   - SNAPSHOT；
   - generic TypeRef；
   - REFERENCE；
   - policy mismatch；
   - missing historical payload。
