# 与上一版原型的区别

上一版只有少量 Foundation Kernel 类型，只能验证模块方向。本版本重新生成完整 V1：

- 生产类型从二十余个扩展到一百四十余个；
- 增加文本、集合、数字、枚举、校验、异常链、时间、ID、编解码、上下文、反射、资源和序列化完整能力域；
- 序列化按同一目录能力域组织，同时继续隔离 API Jar 与 Jackson 实现 Jar；
- 增加内容长度、资源大小和 GZIP 解压限制；
- 增加上下文传播协议，但不写死 ThreadLocal；
- 增加测试支持、28 个测试类和 ArchUnit 规则；
- 补充包级说明、源码索引、构建清单和验证报告。

上一版 ZIP 不建议继续合入正式工程，本版本作为 Foundation Component V1 的审查基线。
