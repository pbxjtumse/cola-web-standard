# 一期设计说明

## 执行顺序

```text
创建逻辑执行
  -> 检查线程中断和总时间
  -> 开始第 N 次尝试
  -> 执行业务操作
  -> 发布尝试完成事件
  -> 分类结果或异常
     -> SUCCESS: 返回成功
     -> STOP: 返回不可重试
     -> ABORT: 返回执行终止
     -> RETRY:
          -> 检查最大尝试次数
          -> 检查最大总时间
          -> 计算退避时间
          -> 检查退避后是否越过总时间
          -> 等待
          -> 下一次尝试
```

## 边界

- 重试控制位于幂等执行器外层，每次实际业务尝试都必须重新进入幂等判断。
- 事务重试必须包裹完整事务模板，而不是在事务内部只重试某一条 SQL。
- 消息组件负责 ACK、NACK、重试主题和死信；本组件只提供重试策略与本地执行能力。
- 长时间重试应转交消息或任务组件，不能长期阻塞业务线程。
